# Chronology: story, history and experience

This is a populated planning chronology for all twelve volumes. All event selections, synthetic consequences and first-safe chapters are **editorial proposals**. Each row is an anchor awaiting full scene development, not a claim that a chapter is complete.

Source-story order is not a calibrated universal timeline. Historical dates remain unknown unless a bounded source supports them. Realm and personal elapsed times remain explicitly unestablished. Composition dates are separate: an exile setting does not date the writing of Daniel.

The historical date discrepancy **587/586 BCE** is preserved. The 538 return tradition and 520 rebuilding resumption are distinct events and not an eighteen-year transit. Date ranges in the data identify whether they are duration, disagreement, context or a grouping of different events.

## Historical references

The northern fall is recorded as 722/721 BCE in the [USCCB historical introduction](https://bible.usccb.org/bible/historicalintroduction/0). The same introduction gives 587 BCE for Judah; the [Israel Antiquities Authority timeline](https://www.deadseascrolls.org.il/learn-about-the-scrolls/historical-timeline) uses 586 BCE. These sources are not silently averaged.

The [Metropolitan Museum’s Cyrus Cylinder exhibition](https://www.metmuseum.org/exhibitions/listings/2013/cyrus-cylinder) supports Cyrus’s capture of Babylon in 539 BCE and explicitly notes that the cylinder does not name the Jews. The [note at Ezra 3:1–2](https://bible.usccb.org/bible/ezra/3) distinguishes an apparent 538 return from building resuming in 520.

The [IAA timeline](https://www.deadseascrolls.org.il/learn-about-the-scrolls/historical-timeline) supplies the bounded 63 BCE, 70 CE and 132–135 CE anchors used here. Its other dates have not been imported wholesale.

## Many-clock contract

Every drafted journey or return must record departure and arrival witnesses, source and destination realm, world elapsed time, personal elapsed time, conversion rule if known, and a changed condition that remains afterward. If a duration is not established, write unknown. Never substitute zero or assume a 1:1 rate.

Example only: a character experiences six hours while seventy-two world hours pass under an adopted constant 1:12 rate. People outside have lived three days. A missed burial, an expired promise or a changed government is still real when the traveller returns. This arithmetic example is not canon for any realm.
