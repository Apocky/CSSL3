# What returns from The Unraveling V2

The new series is not a wholesale reprint or an automatic adoption of every older rule. V2 supplies an awakening crisis, a difficult friendship, Lilith and Eve’s conflict, institutional opponents, the possibility of another route, and an aftermath that matters. Its 50 chapter hooks, prologue, and epilogue each have a disposition below.

The exact source file is preserved. The core identity sections, supporting cast, and complete chapter-hook outline were inspected for this map; not every prose sample and system section was reread.
