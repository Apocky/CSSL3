The Good Book atlas

These three editable SVG maps are editorial proposals around the approved Omnoid frame and twelve-volume plan. Text remains editable; each file has an accessible title and description and uses no external images or fonts.

  1. The Omnoid and the names of passage separates realm geography, gate functions, cultivation vocabularies and HALO. Its containment is conceptual. It does not claim a scientific embedding, measured distances or guaranteed routes.
  2. Historical places and changing routes uses coarse editorial locators for twelve places in the eastern Mediterranean and Mesopotamia. The grid shows approximate relative positions. It does not certify ancient footprints or an Exodus itinerary. Every route is dashed and labelled by its era and evidential status. Global comparison windows retain the wider scope without inventing lines of diffusion.
  3. One history is not one clock gives twelve equal-width reading-order columns and five distinct tracks. Equal widths do not imply equal historical durations. The realm and personal tracks explicitly remain unestablished.

The complete accessible table equivalents are in world reference and chronology; machine-readable place, route, identity and event records are in world.json.

Historical evidence and limits

The Metropolitan Museum’s ancient Near East teaching resource supports regional geographic context. The map’s coordinates are coarse editorial values, not claimed measured data. An attempted Pleiades gazetteer check returned a bot challenge; no challenge was bypassed and no coordinate verification is claimed.

The USCCB historical introduction, IAA timeline, Ezra 3 note and Met Cyrus Cylinder reference support the bounded chronological context used in the legends. The 587/586 BCE discrepancy is preserved.

Editing and reuse

Edit the SVG directly for illustration changes. The generator in the world specification reservation rebuilds the candidate data, tables and original maps; running it will replace these lane-owned generated files, so preserve any hand-edited edition first. Preview PNGs are derived from the SVGs and are not the editable originals. No source manuscript is changed.

Visual QA records are separate from JSON/XML checks. A valid SVG file is not, by itself, visual sign-off.
